# agenxp-langgraph

**agenxp-langgraph** is a high-performance GitHub template repository designed to jumpstart complex **multi-agent AI systems**. It pairs **LangGraph** orchestration with a blazing-fast Python stack powered by **uv** and **FastAPI**.

### 🛠️ Tech Stack
* 🧠 **LangGraph:** Stateful, multi-agent graph architecture and orchestration.
* ⚡ **FastAPI:** High-performance, production-ready asynchronous API layer.
* 📦 **uv:** Ultra-fast Python package resolving, installation, and workspace management.
* 🐳 **Docker:** Ready-to-go containerization for seamless local development and cloud deployment.
